# Evaluator & Submission Guide — SalesAgents AI Hiring Assignment

## 1. Quick Verification for Evaluators
This repository represents the completed submission for the **SalesAgents AI Voice Agent Design Assignment**.

### 30-Second Local Evaluation
1. Clone & Enter Directory:
   ```bash
   git clone https://github.com/REDDIPALLIPHANIKOUSHIK/Voice_Agent_Design.git
   cd Voice_Agent_Design
   ```
2. Run Automated Test Suite:
   ```bash
   python -m pytest tests/ -v
   ```
   *Expected: All 38 tests pass in <0.2 seconds.*
3. Launch Interactive Dashboard:
   ```bash
   python run.py
   ```
   Open `http://localhost:8000/` in Google Chrome or any modern browser.

---

## 2. Interactive Dashboard Features
- **Live Voice Interaction**: Click **Start Call** and speak via microphone using the built-in browser Web Speech engine (English or Hindi).
- **Automated Scenario Simulator**:
  - Select any of the 12 Core Scenarios (T01 - T12) or 7 Adversarial Scenarios (A01 - A07).
  - Click **Run Simulation** to watch the multi-turn conversational exchange, out-of-order fact extraction, and real-time checklist progression.
- **7-Question Checklist Visualizer**: Live checkmarks, answered values, and active question indicator.
- **Qualification State Inspector**: Real-time JSON inspector showing the strongly typed state model.
- **Export Call Log**: Click **Export Log** to download the timestamped conversation and final qualification state.
