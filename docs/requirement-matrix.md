# Requirement Traceability Matrix — SalesAgents AI Voice Agent

## Traceability Mapping
This matrix maps every functional requirement, conversational constraint, and boundary condition from the SalesAgents AI assignment to its implementation file and corresponding automated test.

| Requirement ID | Assignment Requirement | Implementation Location | Verification Test |
| :--- | :--- | :--- | :--- |
| **REQ-01** | **Customer Verification**: Verify speaking with intended customer; do not reveal sensitive financial data beforehand. | `src/engine/orchestrator.py` (`generate_initial_greeting`, Stage 1) | `tests/test_scenarios.py::test_t01_perfect_eligible_customer` |
| **REQ-02** | **Busy Customer Flow**: Acknowledge busy state, capture preferred callback time, end call immediately. | `src/engine/extractor.py` (`extract_busy_or_callback`), `src/engine/orchestrator.py` | `tests/test_scenarios.py::test_t12_busy_customer` |
| **REQ-03** | **Offer Presentation**: Explain pre-approved LAP offer up to ₹75 Lakh warmly and professionally. | `src/engine/orchestrator.py` (`process_utterance` Stage 3) | `tests/test_scenarios.py::test_t01_perfect_eligible_customer` |
| **REQ-04** | **Property Rule**: Residential, Commercial, Industrial eligible; Agricultural immediately disqualified. | `src/engine/rules.py` (`evaluate_property_type`), `src/engine/extractor.py` | `tests/test_rules.py::test_property_type_rules`, `tests/test_scenarios.py::test_t02_agricultural_disqualification` |
| **REQ-05** | **Ownership Rule**: Sole and Joint are both eligible. Joint ownership must NEVER be rejected. | `src/engine/rules.py` (`evaluate_ownership`) | `tests/test_rules.py::test_ownership_rules`, `tests/test_scenarios.py::test_t08_joint_ownership_eligible` |

| **REQ-13** | **Existing Property Loan**: Transfer to loan-transfer specialist; end call immediately. | `src/engine/rules.py` (`evaluate_transfer_condition`), `src/engine/orchestrator.py` | `tests/test_scenarios.py::test_t09_existing_property_loan_transfer` |

| **REQ-16** | **First-Missing Question Selector**: Sequentially ask only the first missing question from 1 to 7. | `src/engine/orchestrator.py` (`get_first_missing_checklist_item`) | `tests/test_scenarios.py::test_t11_out_of_order_answer` |
